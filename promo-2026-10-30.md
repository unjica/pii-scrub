# @tacko/pii-scrub promo — 2026-10-30

## Verified facts (npm registry + GitHub README, run locally in /tmp/pii)

- v0.1.0, MIT, zero dependencies, Node >=18, ESM+CJS, TS types; README says also browsers/edge (not tested by us).
- API: scrubText, scrub (deep, non-mutating), scrubError (keeps prototype), createScrubber.
- Detects: email, JWT, Bearer, API keys (sk-/pk-, Stripe, GitHub, GitLab, Slack, AWS, Google, npm), IBAN (mod-97), Luhn cards, phones (+ / NANP), secret query/key=value/JSON secrets, Cookie/Authorization headers, URL query strings; IPv4/6 off by default.
- README: "This is not a compliance tool... does not make your logs GDPR/HIPAA/PCI compliant".
- Tested output: scrubText("Payment failed for jane@example.com, card 4111 1111 1111 1111") -> "Payment failed for [email], card [card]".
- Caveat found: short fake key "sk_live_abc123XYZ456" was NOT redacted; "sk_live_51HxAbCdEfGhIjKlMnOp" was. Don't use short keys in examples.
